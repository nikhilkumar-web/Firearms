# Firearms (American Firearms Network)

Welcome to the **Firearms** repository.

This repository contains the complete modernized **Next.js** web application for the American Firearms Network ([americanfirearmsnetwork.com](https://americanfirearmsnetwork.com/)).

---

## 📂 Project Location

The entire Next.js codebase is located inside the [`firearms-project/`](./firearms-project) directory:

```text
Firearms/
├── firearms-project/     # Next.js App Router project (JavaScript + Tailwind CSS v4)
│   ├── public/images/   # High-resolution downloaded images & logos
│   ├── src/data/        # Decoupled data models (courses, instructors, ranges, etc.)
│   ├── src/components/  # Modular components (layout, home, forms, ui)
│   └── src/app/         # App router pages & dynamic routes
└── README.md
```

### Quick Start:
```bash
cd firearms-project
npm install
npm run dev
```

For full architecture details and developer guides, please see [`firearms-project/README.md`](./firearms-project/README.md).
